Drop your screenshots in this folder using these exact filenames
so they show up automatically on the site:

profile.jpg   -> your photo (used in the hero section)
act1.png      -> Laboratory Activity 1 screenshot
act2.png      -> Laboratory Activity 2 screenshot
act3.png      -> Laboratory Activity 3 screenshot
act4.png      -> Laboratory Activity 4 screenshot
act5.png      -> Laboratory Activity 5 screenshot

Until a file is added, that spot shows a light placeholder box
with the expected filename, so you can see exactly what's missing.
